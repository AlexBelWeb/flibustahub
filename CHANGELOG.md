# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование следует [Semantic Versioning](https://semver.org/lang/ru/).

Правила ведения:

- запись добавляется **в том же коммите**, где меняется поведение;
- пишем для пользователя, а не для коммитов: «Поиск больше не теряет результаты при быстром вводе», а не «рефакторинг debounce»;
- внутренние рефакторинги без видимого эффекта в changelog не попадают;
- одна запись — одна строка;
- записи, требующие миграции базы, помечаются явно;
- **до релиза `1.0.0` существует только секция `Unreleased`** — версии не нарезаются, даты не ставятся, промежуточные релизы не выпускаются.

## [Unreleased]

### Добавлено

- Каркас десктопного приложения: окно, выбор языка (русский/английский), тёмная и светлая темы.
- Журнал работы пишется в папку данных пользователя и не разрастается бесконечно.
- Второй запуск программы поднимает уже открытое окно вместо второго экземпляра.
- Если настройки не открылись при запуске, окно всё равно появляется с объяснением и возможностью повторить попытку.
- Каталог книг хранится в локальной базе; при обновлении программы схема поднимается сама.
- Перед обновлением схемы уже существующей базы создаётся резервная копия (хранятся последние три).
- На главном экране можно указать папку с книгами и импортировать каталог из файла `.inpx`.
- Пока идёт импорт, окно блокируется: видны текущий этап, число записей и честная полоса по объёму дампа; до записи в базу импорт можно отменить.
- После импорта показывается отчёт: сколько произведений и изданий добавлено или изменено, каких архивов не хватает на диске, какие жанры без названия, кодировки файлов и длительность этапов.
